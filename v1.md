# Project: Interactive Learning Playground

## Vision

Build an interactive web platform that helps children, students, and curious adults learn concepts through exploration instead of memorization.

The platform should feel like a playground, not a textbook.

Users should discover concepts by experimenting and observing outcomes rather than reading long explanations.

The goal is to create frequent "Aha!" moments where users intuitively understand why something happens.

Examples:

* Why does a bulb become dimmer?
* Why does increasing voltage make a bulb brighter?
* Why does an MCB trip?
* Why do series and parallel circuits behave differently?

The platform should eventually support multiple subjects, but Version 1 focuses on electricity.

Core philosophy:

"Learning through exploration, not memorization."

---

# Version 1 Learning Goal

Teach three foundational concepts:

1. A complete circuit is required for electricity to flow.
2. Increasing voltage increases current and bulb brightness.
3. Increasing resistance reduces current and bulb brightness.

A user should understand these concepts without reading formulas.

Must include:

* Positive terminal (+)
* Negative terminal (-)

Changing voltage should instantly affect bulb brightness.

---

## Bulb

* Dim
* Medium
* Bright

## Wire

---

# Connection System

This is one of the most important parts.

Connections must not require pixel-perfect precision.

Each terminal should behave like a magnetic snap point.

Terminal States:

Available:
○

Hover Candidate:
◎

Connected:
●

Behavior:

* User drags from one terminal
* Nearby terminals glow
* Wire snaps automatically
* Connection feels smooth and satisfying

The experience should feel intuitive even for young children.

---

# Circuit Logic

Internally model components as nodes and connections.

Determine:

* Open circuit
* Complete circuit

Only when a complete loop exists should current flow.

When the circuit becomes complete:

* Bulb lights up
* Small visual celebration occurs
* User immediately sees success

The system should teach that electricity requires a complete path.

---

# Learning Design

Do not start with formulas.

Avoid showing:

V = I × R

at the beginning.

Instead:

User changes voltage.

Bulb gets brighter.

Then explanation appears:

"Higher voltage pushes more electricity through the circuit."

User changes resistance.

Bulb becomes dimmer.

Then explanation appears:

"More resistance makes it harder for electricity to flow."

Concepts should emerge from interaction.

---

# Progressive Discovery

Hide complexity initially.

The first experience should be extremely simple.

Only reveal additional information when users show curiosity.

---

# Hover Learning System

Hovering over objects reveals contextual information.

Example:

Hover Live Wire:

Voltage: 9V
Current: 0.09A

Hover Resistor:

Resistance: 100Ω
Voltage Drop: 5V

Hover Bulb:

Power: 0.4W
Brightness: Medium

Information should appear in small tooltips.

Avoid permanently displaying numbers.

---

# Wire Colors

Use realistic electrical color conventions.

Live Wire:

Brown

Neutral Wire:

Blue

Future:

Earth Wire:
Green/Yellow

This helps teach real-world electrical concepts naturally.

---

# Current Flow Visualization

Optional toggle:

When enabled:

* Small animated particles move through wires
* Direction of flow becomes visible
* Current path becomes easier to understand

Default:

Disabled

This keeps the interface clean for beginners.

Make the bulb brighter.

The platform should reward curiosity rather than provide direct answers.

# Success Metric

The project succeeds if users naturally ask questions such as:

* Can I add another battery?
* Why did the bulb get brighter?
* What happens if I remove this wire?
* Can I connect two bulbs?

These questions indicate curiosity has been activated.

The goal is not to teach facts.

The goal is to inspire exploration.
